# ミッション：パートナー関係の心の伴走者アプリ「Welfamily」の自律的開発と検証

## 1. ミッション概要
あなたはGoogle Antigravity内で稼働する自律型エンジニアエージェントです。
私（Welfamilyの杉原）が手掛ける夫婦・パートナーとの関係改善サービスの知見をもとに、夫婦関係に悩む方が日々の悩みや心配事を投げかけた時に、優しく寄り添いワンポイントでアドバイスをくれる「心の伴走者」のようなWebアプリ「Welfamily」をエンドツーエンドで開発し、検証まで完了させてください。

## 2. 参照データ・ナレッジ
以下のオンラインデータおよびテキストをブラウジング・読み込みし、アプリ内のAI（Gemini）のシステムプロンプトのベース知識として組み込んでください。
・記録フォルダ1: https://drive.google.com/drive/folders/162W_r3XoGzLlpe_TPcNYYPg-S3bm1MmC
・記録フォルダ2: https://drive.google.com/drive/folders/1V9WsB5-MGnE-Vrr0TUjfzWFylyGHgBY9
・必須の心理学ナレッジ：女性脳の共感欲求の高さ、会話の目的の違い（女性は共感・男性は解決）、「事実の通信線」の前に「心の通信線」を繋ぐことの重要性、不満の蓄積（セキュリティ問題）。

## 3. システム・技術要件
・言語/フレームワーク: Python, Streamlit
・使用するAPI: Google Gemini API (google-generativeai の最新版)
・アプリ内AIモデル: `gemini-2.5-flash` を指定。
・APIキーのセキュアな管理: ユーザーに画面入力させず、StreamlitのSecrets機能（`st.secrets["GEMINI_API_KEY"]`）を使用すること。

## 4. アプリ内AIの振る舞い要件（System Instruction）
アプリ内でGeminiモデルを初期化する際の `system_instruction` には以下を含めてください。
1. 「Welfamily」というブランド名でユーザーに優しく寄り添う心の伴走者として振る舞うこと。
2. ユーザーの感情（不安、怒りなど）を絶対に否定せず、まずは深く受け止めて共感すること。
3. 問題解決や正論を急ぐのではなく、相手の心を肯定する「心の通信線」を繋ぐことを最優先にすること。
4. 長すぎない温かいトーンで、今日から実践できる「ワンポイントアドバイス」を添えること。

## 5. エージェントの実行ワークフロー（Antigravity Agentへの指示）
以下のフェーズに従って自律的に作業を進め、各フェーズでArtifact（生成物・証明）を提示してください。

- **Phase 1: Plan (計画)**
  開発を始める前に、実装計画とタスクリスト（Artifact）を生成してください。
- **Phase 2: Build (実装)**
  `app.py`、`requirements.txt` を実装してください。また、ローカル検証用に `.streamlit/secrets.toml` を作成してダミーのAPIキーを設定し、必ず `.gitignore` に追加してシークレット漏洩を防いでください。
- **Phase 3: Verify (検証)**
  1. Antigravityのターミナルでローカルサーバー（`streamlit run app.py`）を起動すること。
  2. 統合ブラウザを開き、UIの表示崩れやエラーがないか視覚的に確認すること。
  3. アプリのチャット欄に「最近、パートナーが冷たくて会話がなく、不安です」とテスト入力し、設計したシステムプロンプト通りに共感的なレスポンスが返るか検証すること。
  4. 検証の証拠として、チャット応答のスクリーンショットおよび動作ログ（Artifact）を私（ユーザー）に提出すること。
- **Phase 4: Iterate (自己修復)**
  万が一エラーが出た場合、または応答が要件を満たしていない場合は、人間の介入を待たずに自己修復ループ（Self-repair loop）を回し、完全に動作する状態にしてから報告してください。
